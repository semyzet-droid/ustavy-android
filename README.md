# Уставы • офлайн

Android-приложение для изучения общевоинских уставов на Samsung S25 Ultra (ARM64).

- Поиск по словам, фразам и точному номеру статьи/пункта.
- Чтение, закладки, карточки для повторения и статистика.
- Импорт TXT UTF-8 с телефона.
- Встроенный локальный ИИ: llama.cpp + Qwen2.5-1.5B-Instruct Q4_K_M.
- Объяснения и вопросы по выбранной статье; источник остаётся рядом.
- Нет разрешения INTERNET; интерфейс загружается из APK, без внешних ресурсов.

## Установка
Скачайте APK из Releases. Размер около 1,2 ГБ. Для первой распаковки модели нужно ещё около 1,2 ГБ.
Это тестовая APK со стандартной отладочной подписью. На реальном S25 Ultra ещё не проверена.
Не очищайте данные приложения без сохранения исходных TXT: закладки, прогресс и импортированные документы хранятся локально.
Стабильную release-подпись для обновлений нужно настроить перед распространением.

## Тексты
Сборка пытается получить три общевоинских устава из Указа №1495 с официальных pravo.gov.ru или kremlin.ru.
ASSET_REPORT.json сообщает состав подборки и ошибки загрузки.
Актуальность редакции на дату использования не гарантируется. Если официальный источник недоступен, резервная копия устава внутренней службы явно помечается как архивное издание 2007 года. Если источник недоступен, приложение явно предлагает импорт TXT.
Строевой устав пока добавляется через импорт.
ИИ может ошибаться: объяснение нужно сверять с оригинальным текстом.

## Проверки
В CI проверяются офлайн-поиск, точные номера (12 / 12.1 / 120), ё/е, сохранение закладок, карточки и разбиение текста.
Затем собирается APK, проверяется подпись и отсутствие INTERNET.
Скорость и качество ИИ на целевом телефоне требуют проверки после установки.
